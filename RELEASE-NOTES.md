Sill for Windows 0.1.1 adds menus.

- **Menus:** the Menus button in Sill's bar now shows the menus of the window you're using, and tapping an item chooses it on the PC. This works for programs with classic Windows menus, such as Device Manager, Notepad++, 7-Zip, Audacity and FileZilla. Most newer apps, like Chrome, Office, File Explorer and the new Notepad, draw their own menus, which Windows gives no way to read, so Sill says so instead.

**This is still an early release.** It hasn't yet run on a real PC with a real iPad. Video from a real graphics chip, streaming one window or a second monitor, and a real iPad finding the PC over Wi-Fi are all still untested. If something fails, open an issue and attach `Sill-log.txt` from the program's folder.

- **SillSetup.exe** is the installer. It sets up the firewall for you. Start here.
- **SillHost.exe** is the single program, with nothing to install.

Sound isn't in these downloads. Windows will show a blue warning because the program isn't signed yet. Click More info, then Run anyway.

Setup steps are at https://sillforwindows.tanookistudios.com
