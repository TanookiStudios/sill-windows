First public release of Sill for Windows, an unofficial Windows program that lets the Sill app on an iPad or iPhone show and control your PC.

**This is an early release.** It has not yet been run on a real PC with a real iPad. Video from a real graphics chip, streaming one window or a second monitor, and a real iPad finding the PC over Wi-Fi are all still untested. If something fails, open an issue and attach `Sill-log.txt` from the program's folder.

- **SillSetup.exe** is the installer. It sets up the firewall for you. Start here.
- **SillHost.exe** is the single program, with nothing to install.

Sound isn't in these downloads. Windows will show a blue warning because the program isn't signed yet. Click More info, then Run anyway.

Setup steps are at https://sillforwindows.tanookistudios.com
